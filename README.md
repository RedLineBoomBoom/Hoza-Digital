## ⚡ Tentang Hoza Digital

**Hoza Digital** adalah studio produk digital berkecepatan tinggi (*high-velocity digital engineering studio*) yang beroperasi secara *remote-first* dengan basis operasional di **Jakarta (UTC+7)** dan **Singapura (UTC+8)**. 

Kami merancang dan membangun arsitektur digital berstandar enterprise yang menggabungkan:
- **Zero Runtime Bloat**: Eksekusi kode deterministik tanpa beban dependensi berlebih.
- **Sub-Second Velocity**: Responsivitas instan dengan waktu muat halaman *sub-second* dan skor Lighthouse mendekati 100/100.
- **Fluid Cyberpunk UI/UX**: Estetika antarmuka modern yang memadukan aksen neon cyber (*Electric Cyan* `#00F0FF`, *Signature Violet* `#8B5CFF`, dan *Deep Void* `#08050D`).

## 🌟 Fitur Interaktif & Keunggulan Antarmuka

### 1. Cyber Spatial 3D Hero Canvas
Visualisasi partikel 3D berbasis **Three.js** dan WebGL interaktif dengan orbit simpul teknologi dan *floating terminal CLI* yang dapat digeser (*draggable*).

### 2. Kursor Cyberpunk Dinamis (Official Hoza Emblem)
Kursor kustom presisi tinggi yang menggunakan lambang bulat resmi Hoza (`HozaEmblem`):
- **Titik Inti Laser**: Pointer putih-panas nol latensi (*zero input lag*) dengan pendaran cyan.
- **Follower Lambang Bulat Hoza**: Cincin terluar berputar (*rotating cyber dashed ring*) melingkupi poligon oktagonal "O" khas Hoza.
- **Fisika Kemiringan Aerodinamis**: Kemiringan dinamis halus (*banking tilt* hingga 14°) saat mouse bermanuver cepat.
- **Interaksi Hover & Klik**: Otomatis membesar dan mengunci target saat mengarah ke tombol/link, serta memancarkan gelombang kejut (*shockwave*) dan percikan partikel (*stardust sparks*) saat diklik.

### 3. Infinite Seamless Ticker & Marquee
Pergerakan teks tanpa henti berbasis arsitektur **Dual-Track Synchronized Looping** tanpa jeda atau sentakan visual:
- **Articles Section**: Marquee berjalan menampilkan kata `ARTICLES` berukuran sedang yang proporsional berdampingan dengan logo bulat Hoza.
- **Client & Ecosystem Marquee**: Menampilkan mitra ekosistem terpercaya (Solflare, MonkeDAO, SwissBorg, Raposa, Superteam, dll.).
- **Footer Statement Ticker**: Pernyataan filosofi dan prinsip deterministik Hoza Digital.

### 4. Audio Engine Real-Time (Web Audio API)
Efek audio sintetis mikro tanpa file eksternal untuk respon taktil klik dan hover (*synthesized frequency chimes*).

### 5. Floating Cyber Dock Navigation
Navigasi pintar yang melayang di bagian bawah layar dengan indikator status aktif, jam ganda real-time (Jakarta UTC+7 & Singapura UTC+8), tombol lompat cepat antar section, dan drawer modal terintegrasi.

## 🚀 Memulai Pengembangan Lokal

### Prasyarat
- **Node.js**: Versi `18.18.0` atau lebih tinggi
- **npm**, **yarn**, atau **pnpm**

### Langkah Instalasi

1. **Clone Repositori**:
   ```bash
   git clone https://github.com/RedLineBoomBoom/Hoza-Digital.git
   cd Hoza-Digital
   ```

2. **Pasang Dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan Server Pengembangan**:
   ```bash
   npm run dev
   ```
   Buka browser dan akses [http://localhost:3000](http://localhost:3000).

4. **Kompilasi Produksi & Type-Check**:
   ```bash
   npm run build
   npm run start
   ```
