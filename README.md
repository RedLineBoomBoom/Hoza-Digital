## 🌟 Interactive UI & Architectural Highlights

### 1. Cyber-Spatial 3D Hero Canvas
An interactive 3D particle system built on **Three.js** and WebGL featuring orbiting technology nodes and a draggable floating CLI terminal runner.

### 2. Dynamic Cyberpunk Cursor (Official Hoza Emblem)
A custom hardware-accelerated precision cursor utilizing the official circular Hoza emblem (`HozaEmblem`):
- **Laser Dot Core**: White-hot zero-latency pointer core (`#ffffff`) with cyan neon halo (`#00F0FF`) ensuring 100% click precision.
- **Follower Hoza Emblem**: A continuously rotating cyber dashed ring (`animate-[spin_10s_linear_infinite]`) enclosing the iconic octagonal "O" polygon.
- **Aerodynamic Banking Tilt**: Smooth aerodynamic banking rotation (up to 14°) based on cursor velocity when sweeping across the screen.
- **Hover & Click Dynamics**: Seamlessly expands to 1.35x and shifts to electric cyan when locking onto interactive targets; produces tactical shockwaves and stardust sparks upon clicking.

### 3. Infinite Seamless Tickers & Marquees
Continuous kinetic motion powered by an industrial-grade **Dual-Track Synchronized Looping** architecture (`translateX(-100%)`):
- **Articles Section**: A balanced medium-sized marquee displaying the bold wordmark `ARTICLES` alternating with the circular Hoza emblem.
- **Client & Ecosystem Marquee**: Displaying trusted partners and ecosystem projects (Solflare, MonkeDAO, SwissBorg, Raposa, Superteam, etc.).
- **Footer Principles Ticker**: High-impact statements articulating Hoza's engineering philosophy.

### 4. Real-Time Web Audio Engine
Micro-synthesized audio feedback generated in real time using the browser's native Web Audio API—producing subtle tactical chimes upon clicking and hovering without external audio assets.

### 5. Floating Cyber Dock Navigation
An ambient navigation dock floating at the bottom of the viewport equipped with live dual clocks (Jakarta UTC+7 & Singapore UTC+8), section shortcuts, and an integrated project enquiry modal drawer.
